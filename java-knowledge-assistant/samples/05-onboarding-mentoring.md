# 模拟资料：首月导师与学习安排

本文由本学习项目自编，所有团队、设备、金额和制度均为模拟，不对应真实单位，不作为现实操作或财务建议。资料版本：1。

## 每周同步

导师与 Java 实习生每周四16:00进行20分钟学习同步。学生在周四12:00前提交三项内容：已完成任务、遇到的一个问题、下一步计划。

## 代码练习

第二周练习为模拟库存查询接口增加边界值校验，先写失败用例再改代码。提交时需附测试命令和实际结果，不允许在报告中填写没有执行的成绩。

## 提问方式

遇到运行失败时记录时间、错误码、最小复现步骤和已尝试的方法，再向导师提问。不得在学习日志中粘贴密钥或真实个人资料。

## 范围边界

本文只规定学习安排，没有规定转正条件、工资涨幅、录用保证或考试通过率。
