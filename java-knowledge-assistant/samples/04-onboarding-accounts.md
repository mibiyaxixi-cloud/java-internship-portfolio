# 模拟资料：账号与权限申请

本文由本学习项目自编，所有团队、设备、金额和制度均为模拟，不对应真实单位，不作为现实操作或财务建议。资料版本：1。

## 工单必填项

新成员申请开发账号时，由直属负责人填写模拟工单，记录姓名代号、所属小组、岗位、所需系统和到期日期。实习账号默认有效期为90个自然日；延长须在到期前3个工作日重新申请。

## 仓库权限

Java 实习生默认获得学习仓库的读取权限。提交练习需申请个人分支写入权限，由导师确认。生产数据库、发布平台和支付系统权限不在实习默认授权范围内。

## 账号停用

成员离组当日由负责人通知模拟 IT 服务台停用账号。账号停用不代表删除知识库文档；文档状态由知识库管理员单独管理。

## 未规定事项

本文不含真实服务地址、口令、访问令牌或薪资信息，也没有规定个人账号能访问哪些真实业务数据。
