# 模拟资料：共享设备操作手册

本文完全自编，仅用于学习演示。设备型号和位置均为虚构信息，不作为真实设备安全操作指引。资料版本：1。

## 打印机使用

模拟打印机编号 PR-02，位于 B 区资料角。打印普通内部资料时选择 A4、黑白、双面。打印前先在预览中核对页数。涉及个人资料的文件不得上传到本演示系统。

## 打印卡纸

PR-02 显示卡纸时先取消当前任务，再按面板的停止键。不要强拉纸张或拆开设备。记录屏幕错误码并联系模拟 IT 服务台，由指定维护人员处理。

## 会议屏连接

模拟会议室 C1 的显示屏使用 HDMI 连接。先选择屏幕输入源 HDMI 1，再在电脑上选择复制屏幕。会议结束后退出账号、断开连接并收好线缆。手册未包含无线投屏配置。

## 设备借还

键鼠和 HDMI 转接器需要在模拟借用登记表记录借用人、资产编号和预计归还时间。普通借用应在 3 个工作日内归还；延期需管理员确认。归还时由管理员检查配件并关闭借用记录。
