# 模拟资料：学习笔记本借用

本文由本学习项目自编，所有团队、设备、金额和制度均为模拟，不对应真实单位，不作为现实操作或财务建议。资料版本：1。

## 借用期限

学习笔记本型号为虚构的 L-Study-3，借用期为10个工作日。借用前由管理员登记设备编号、适配器编号、外观检查结果和归还日期。此期限仅用于学习笔记本，不替代键鼠和转接器的3个工作日期限。

## 软件环境

设备预置模拟 Java 21 学习环境。新增软件须提交软件名称、用途和许可证说明给模拟 IT 服务台；不要求购买任何服务。

## 异常上报

设备无法启动时停止重复尝试，记录指示灯状态和最后一次正常使用时间，并联系模拟 IT 服务台。本文不是实际硬件维修指南。

## 归还验收

归还时管理员核对设备和适配器编号，学生删除自己的模拟练习副本并退出账号。管理员确认后关闭借用记录。本文没有规定赔偿金额。
