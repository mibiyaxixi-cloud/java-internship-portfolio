# 模拟资料：报销材料检查

本文由本学习项目自编，所有团队、设备、金额和制度均为模拟，不对应真实单位，不作为现实操作或财务建议。资料版本：1。

## 模拟票据核对

检查模拟票据编号、费用日期、金额与申请表是否一致。演示票据统一使用 DEMO 前缀，禁止上传真实发票或银行账户。

## 重复申请

同一模拟票据编号不得重复申请。发现重复时由财务协调员退回并说明原因；知识库问答只解释规定，不修改申请或执行付款。

## 缺失材料

缺少费用用途或票据编号时，申请退回补充；补齐前不开始计算审批通过后5个工作日的付款安排期限。

## 金额与更正

金额不一致时提交人应先核对原始练习数据，再重新提交申请。本文不规定真实税务抵扣规则，也不授权修改任何真实财务数据。
