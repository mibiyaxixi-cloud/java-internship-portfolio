## 覆盖与错误路径

| 检查 | 实际断言 |
|---|---|
| 历史销售 | REFUNDED 快照仍保留支付日销售；退款仅计退款日；取消订单不产生资金事件 |
| 日期边界 | 23:59:59 支付归前日，00:00:00 退款归后日；范围右边界排除；闰日及无事件日补零 |
| 粒度 | 两行订单只累加一次整单金额；商品/事件明细累加行金额；单商品退款下钻不带入前日支付 |
| 过滤与分页 | 按日期、门店、商品、事件；相同时间分页稳定、无重复漏行；订单 CSV 与台账的下单日/状态一致 |
| 权限 | 未登录 401；门店指定别店对总览、明细和两类导出均 403；伪造 ADMIN authority 无效，数据库角色为准 |
| 输入错误 | 缺失/非法日期、反向/超长/越界日期、未知商品、非法事件、非法分页 400；导出错误为 JSON，无附件头 |
| CSV | 真实导入含逗号、双引号和公式起始的订单号，导出正确转义并加文本前缀；空白/控制/全角/格式字符前缀单元验证 |
| 导出上限 | 测试库独有夹具 10,000 条订单/明细，两类导出均完整读取 20 个 SQL 分页；验证行数、唯一 ID、顺序、金额；第 10,001 条返回 422 EXPORT_LIMIT |
| 字节上限 | 单元测试超过 16 MiB 时抛 EXPORT_TOO_LARGE，不返回部分附件 |
| 操作记录 | 生成成功记录包含账号/筛选/数量；读取只按当前账号，不接受 actorId |
| M1 回归 | 错行整批无业务半成品、独立失败记录、同内容幂等、同号冲突、并发确认、越权导入继续通过 |

10,000 行夹具仅用于导出上限与分页正确性验证，结束按随机门店限定删除。本阶段没有把这些执行时间写成查询基准，没有测 10 万明细或宣称索引带来提升。后端请求受 30 秒事务和文件/行数上限限制，不等于已经做过压力测试。

## 可复现步骤与限制

```bash
./scripts/dev-db.sh start
./scripts/backend.sh verify
(cd frontend && npm ci && npm run build)
# 另一个终端从项目根目录启动后端；前端 npm run dev
./scripts/backend.sh run
# 演示文件未导入时，先按 README 网页导入或运行 smoke.mjs
API_BASE=http://127.0.0.1:5174/api node scripts/smoke-m2.mjs
```

集成测试只使用 `TEST_DB_*`；库名保护在 Flyway 前执行。不要并行跑多个套件。HTTP 冒烟固定核对演示日期，若用户添加同日期业务订单，金额断言可能失败；不允许为了让测试通过而清空用户数据，应改用隔离夹具测试。

CSV 为有上限的内存完整生成，数据库分批读取；不是异步或无限流式导出。单次请求内部快照一致，不跨 HTTP 请求冻结数据。公式防护不保证经各类表格软件二次保存后仍安全。导出日志代表服务器生成成功，不代表浏览器落盘；生产部署、并发吞吐、数据库离线恢复均未测试。
