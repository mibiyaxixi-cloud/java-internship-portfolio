# 简历项目经历 · Java 后端方向

以下描述以已存在的源码和验收记录为依据。项目属于在 AI 辅助下完成的个人学习实践；投递前应亲自运行、能解释核心设计，并按自己实际参与的内容使用。

## BookFlow · 实验室设备预约与候补调度平台

**技术栈：Java 21、Spring Boot、Spring Security、MyBatis、MySQL、Vue 3**

- 实现设备与时段管理、登录鉴权、预约取消、个人记录和管理员操作，使用 Session、BCrypt、CSRF 及后端归属校验控制访问。
- 使用 MySQL 事务、固定顺序行锁与唯一约束控制同一时段有效占用；持久化用户级幂等键，使成功请求重试返回原响应。
- 实现候补排队、限时确认、超时递补和持久化任务恢复，并通过真实 MySQL 并发用例验证竞争场景。

## 门店订单与经营报表后台

**技术栈：Java 21、Spring Boot、MyBatis、MySQL、Vue 3、ECharts**

- 实现 CSV 预检查与整批事务导入，结合文件哈希、订单唯一约束及独立失败记录处理重复导入和异常回滚。
- 实现服务端门店数据权限，以及按支付、退款发生日期统计的报表、原始订单下钻和 CSV 导出，使用整数分处理金额。
- 在本机模拟数据集上使用 EXPLAIN/EXPLAIN ANALYZE 分析订单分页查询，增加组合索引并保存对照 SQL、计时样本与复现说明。

可选量化句（仅在能复现和解释时使用）：在 5 万单、10 万明细的本机数据集上，指定退款分页查询扫描行数由 4,173 降至 20；此结果不代表生产环境或全部查询。
